QR Codes das sete estações

Imprima e coloque cada código na estação correspondente. Os códigos deste protótipo não dependem de internet.

Mapa artístico, não geolocalização real. A coleção fica salva neste aparelho. Para usar a câmera, publique em HTTPS (por exemplo, GitHub Pages); alguns navegadores não oferecem leitura nativa de QR. A opção de inserir o código funciona sem câmera. Para uso offline, abra uma vez o PWA pela internet e permita que os arquivos sejam armazenados.
